# Fee schedule source of truth
MDR fees and VAT on fees are taken from the acquirer settlement file at the bank's own grain. Finance never
recomputes fees per transaction line; differences are investigated against the bank file.

# Negotiation position
The e-commerce MID carries about 65 percent of card volume, which supports asking the acquirer for a lower
blended MDR on mada debit at the next contract renewal.

# رسوم الخدمة
تؤخذ رسوم الخصم ورسوم ضريبة القيمة المضافة عليها من ملف التسوية البنكي كما هي دون إعادة احتسابها.
